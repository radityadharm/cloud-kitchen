# 05 — Menu & Strategi Pricing

Sumber data lengkap: [`data/menu-pricing.csv`](../data/menu-pricing.csv).

## Prinsip Penetapan Harga

1. **Harga untuk delivery, bukan dine-in.** Karena komisi platform ~20–25%, harga di
   aplikasi di-*mark up* wajar agar margin bersih tetap sehat setelah komisi.
2. **Target COGS bahan:** makanan ±40–45%, kopi ±33–40% (setelah packaging). Ini realistis
   untuk pasar Indonesia; margin dijaga lewat volume dan bundling, bukan porsi terlalu kecil.
3. **Psikologi harga:** angka bulat/ramah (Rp23.000, Rp25.000) memudahkan keputusan.
4. **Anchor & upsell:** paket komplit (2 pc) & add-on (extra nasi/sambal/saus) menaikkan
   nilai order tanpa banyak menambah biaya tetap.

## Strategi Promo

- **Promo pembuka** (bulan 1–2): diskon 20–30% / gratis ongkir (manfaatkan program subsidi
  platform) untuk mengumpulkan rating & ulasan.
- **Buy 1 Get 1 minuman** di jam sepi (sore) untuk mendorong brand Kopi Sore.
- **Voucher repeat** via stiker di kemasan → arahkan ke WhatsApp untuk order tanpa komisi.
- **Bundling** sebagai default tampilan agar AOV terangkat sejak awal.
